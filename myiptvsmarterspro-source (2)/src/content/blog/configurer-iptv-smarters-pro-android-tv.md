## Pourquoi IPTV Smarters Pro sur Android TV ?

**Android TV est la plateforme la plus simple pour l'IPTV : l'application IPTV Smarters Pro s'y installe depuis le Play Store et se configure en moins de 5 minutes.** Box Xiaomi, Nvidia Shield, Chromecast Google TV, TCL, Philips ou box opérateur : le processus reste identique, avec un [abonnement IPTV](/iptv-france/) actif et votre code IPTV sous la main.

À la différence du [Fire Stick](/blog/installer-iptv-smarters-pro-fire-stick/), nul besoin ici de l'application Downloader : Google certifie l'application pour la plupart des appareils Android TV.

## Étape 1 : installer IPTV Smarters Pro depuis le Play Store

**L'installation depuis le Play Store est la méthode recommandée : mises à jour automatiques et sécurité garantie.**

1. Sur l'écran d'accueil Android TV, ouvrez le **Google Play Store** ;
2. Utilisez la loupe et tapez **IPTV Smarters Pro** ;
3. Sélectionnez l'application et cliquez sur **Installer** ;
4. Patientez quelques secondes puis ouvrez **Ouvrir**.

### Alternative : installation par APK

Si votre box n'affiche pas l'application (box non certifiée Google), deux solutions :

- **Downer / navigateur intégré** : téléchargez l'APK officiel directement sur la box ;
- **Sideload via USB** : copiez l'APK sur une clé, activez **Paramètres > Préférences relatives à l'appareil > Sources inconnues**, puis installez avec un explorateur de fichiers.

## Étape 2 : configurer votre code IPTV

**La connexion recommandée sur Android TV est le mode Xtream Codes API : trois champs, une seule fois.**

1. Ouvrez **IPTV Smarters Pro** ;
2. Cliquez sur **Ajouter un utilisateur** ;
3. Choisissez **Se connecter avec Xtream Codes API** ;
4. Complétez les champs :

| Champ | Contenu | Exemple |
|---|---|---|
| Nom du profil | Nom libre de votre choix | `Salon` |
| URL du serveur | Adresse fournie par e-mail | `http://serveur.exemple:port` |
| Identifiant | Utilisateur Xtream Codes | `user1234` |
| Mot de passe | Mot de passe Xtream Codes | `••••••••` |

5. Validez par **Ajouter un utilisateur** : live, films et séries se synchronisent.

**Attention aux pièges classiques** : pas de `/get.php` dans l'URL, pas de barre oblique finale, aucun espace involontaire. Le guide [où trouver votre code IPTV](/blog/code-iptv-activation/) vous montre exactement où chaque information se trouve dans l'e-mail de confirmation.

## Étape 3 : les réglages qui changent tout sur Android TV

**Trois réglages transforment la lecture d'IPTV Smarters Pro sur Android TV, surtout en 4K :**

- **Décodeur vidéo** : dans Paramètres > Lecteur, sélectionnez **HW** (matériel) — le décodage utilise la puce de la box, plus fluide et moins énergivore ;
- **Tampon** : réglez-le sur **Moyen** pour absorber les variations de débit sans ajouter de latence ;
- **EPG** : activez la mise à jour automatique toutes les **24 heures** et conservez 1-2 jours de guide passé.

Sur les box peu puissantes, en cas d'image noire ou de son sans image, le passage à un **lecteur externe** (VLC ou MX Player) règle le problème en deux clics : Paramètres > Lecteur > Lecteur vidéo externe.

## Dépannage Android TV : les causes fréquentes

| Symptôme | Cause | Correction |
|---|---|---|
| « Login failed » | URL tronquée ou espace caché | Recopiez l'URL sans `/get.php`, collage propre, majuscules respectées |
| Chaînes mais pas de VOD | Identifiants M3U au lieu d'Xtream | Reconnectez-vous en mode Xtream Codes API |
| Image saccadée en 4K | Wi-Fi 2,4 GHz saturé | Passez en 5 GHz ou câble Ethernet |
| EPG vide au premier lancement | Guide en cours de téléchargement | Attendez 1-2 min, forcez la mise à jour |
| Application se ferme seule | Mémoire de la box saturée | Fermez les apps en arrière-plan, redémarrez la box |

Pour les cas plus rares (erreur 403, coupures à 20 h, DNS), l'article [IPTV Smarters Pro ne fonctionne pas : 12 solutions](/blog/iptv-smarters-pro-ne-fonctionne-pas/) passe chaque scénario en revue.
