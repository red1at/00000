## L'IPTV sur iPhone : la configuration la plus rapide

**iOS est la plateforme où IPTV Smarters Pro s'installe le plus vite : App Store, trois champs, et la télévision direct plus la VOD débarquent sur l'écran de l'iPhone en moins de 2 minutes.** Il suffit d'un [abonnement IPTV](/iptv-france/) actif et de votre code IPTV.

L'application couvre l'iPhone comme l'iPad, avec une interface adaptée aux deux tailles d'écran — parfaite pour le match dans les transports ou les séries au lit.

## Étape 1 : installer l'application depuis l'App Store

**IPTV Smarters Pro se télécharge depuis l'App Store comme n'importe quelle application iOS.**

1. Ouvrez l'**App Store** sur votre iPhone ou iPad ;
2. Recherchez **IPTV Smarters Pro** ;
3. Appuyez sur **Obtenir** et validez par Face ID ou Touch ID ;
4. Ouvrez l'application une fois le téléchargement terminé.

> Si l'application n'apparaît pas dans votre région à un moment donné, les applications compatibles Xtream comme **IPTVX** se connectent au même abonnement avec les mêmes identifiants. Notre [guide du code IPTV](/blog/code-iptv-activation/) détaille le format des informations à saisir.

## Étape 2 : configurer votre code IPTV

**La connexion Xtream Codes reste identique sur iOS : trois informations collées depuis votre e-mail de confirmation.**

1. Ouvrez **IPTV Smarters Pro** et touchez **Add User** ;
2. Sélectionnez **Login with Xtream Codes API** ;
3. Renseignez les champs :

| Champ | Contenu | Où le trouver |
|---|---|---|
| Profile name | Nom libre (`iPhone`, `iPad`) | Votre choix |
| Server URL | Adresse du serveur | E-mail de confirmation |
| Username | Identifiant Xtream | E-mail de confirmation |
| Password | Mot de passe Xtream | E-mail de confirmation |

4. Touchez **Add User** : live, films et séries se chargent instantanément.

La connexion Xtream active automatiquement l'EPG, les pochettes VOD et le suivi des épisodes — bien plus confortable qu'un lien M3U sur iPhone.

## Étape 3 : les réglages iOS qui comptent

**Trois réglages iOS améliorent nettement la lecture IPTV Smarters Pro sur iPhone et iPad :**

- **Wi-Fi prioritaire** : vérifiez dans Réglages > Wi-Fi que vous êtes bien sur votre box 5 GHz pour la 4K ;
- **Données cellulaires** : activez la lecture en 4G/5G dans les réglages de l'application et fixez une limite d'usage si votre forfait est restraint ;
- **Mode économie d'énergie** : désactivez-le pendant la lecture, iOS bride alors les performances réseau et vidéo.

## Envoyer l'image sur la TV depuis l'iPhone

**Trois méthodes diffuses l'IPTV de l'iPhone vers le grand écran, sans installer quoi que ce soit sur la TV :**

| Méthode | TV compatible | Démarrage |
|---|---|---|
| **AirPlay** | LG webOS 4+, Samsung récents, Apple TV | Centre de contrôle > Screen Mirroring |
| **Cast intégré** | Chromecast, Android TV, TV Google | Icône Cast dans l'application |
| **Câble HDMI** | Toutes TV (adaptateur Lightning/USB-C) | Adaptateur vers HDMI |

La méthode AirPlay est la plus fluide sur les TV LG et Samsung récentes ; notre [guide Smart TV Samsung et LG](/blog/installer-iptv-smarters-pro-smart-tv/) couvre l'installation native pour un usage permanent.

## Dépannage iOS : les 4 cas fréquents

| Symptôme | Cause | Solution |
|---|---|---|
| « Login failed » | URL incomplète ou espace collé | Recopiez l'URL sans `/get.php`, vérifiez le collage |
| Vidéo sans son | Mode silence iOS activé | Basculez le commutateur latéral, montez le volume |
| Image figée en 4G | Débit mobile instable | Passez temporairement en qualité HD dans les réglages |
| Cast introuvable | TV et iPhone sur des réseaux différents | Placez les deux appareils sur le même Wi-Fi |

Pour les problèmes généraux (403, coupures du soir, DNS), le guide [IPTV Smarters Pro ne fonctionne pas : 12 solutions](/blog/iptv-smarters-pro-ne-fonctionne-pas/) s'applique aussi à iOS.
