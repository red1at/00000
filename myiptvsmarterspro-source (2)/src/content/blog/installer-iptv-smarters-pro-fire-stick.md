## Ce qu'il vous faut avant de commencer

**Pour installer IPTV Smarters Pro sur Fire Stick, il vous faut un abonnement IPTV actif, une connexion Wi-Fi stable et environ 10 minutes.** Voici la liste complète :

- Un **Amazon Fire Stick** (2e génération minimum, Fire Stick 4K recommandé) connecté à votre téléviseur ;
- Un **abonnement IPTV Smarters Pro** actif — [commandez-le sur notre page tarifs](/#tarifs) si ce n'est pas encore fait ;
- Votre **code IPTV** reçu par e-mail : adresse du serveur, identifiant et mot de passe Xtream Codes ;
- Une connexion **Wi-Fi 2,4 GHz ou 5 GHz** d'au moins 10 Mbit/s (25 Mbit/s pour la 4K).

Le même code fonctionne aussi sur vos autres appareils : voir notre [guide Android TV](/blog/configurer-iptv-smarters-pro-android-tv/) et le [site IPTV Smarters Pro France](/) pour toutes les plateformes.

## Étape 1 : activer les sources inconnues sur Fire Stick

**Fire TV n'accepte que les applications de l'Appstore par défaut : il faut d'abord autoriser l'installation depuis des sources inconnues.** Cette manipulation se fait une seule fois et ne présente aucun risque pour votre appareil.

1. Sur l'écran d'accueil du Fire Stick, allez dans **Paramètres** (engrenage à droite) ;
2. Sélectionnez **Mon Fire TV** ;
3. Ouvrez **Options pour développeurs** ;
4. Activez **Applications de sources inconnues** ;
5. Confirmez par **Activer**.

> Astuce : si le menu « Options pour développeurs » n'apparaît pas, cliquez 7 fois de suite sur le nom de votre appareil dans Paramètres > Mon Fire TV : le menu se débloque.

## Étape 2 : installer l'application Downloader

**Downloader est l'outil officiel d'Amazon qui permet de télécharger les fichiers APK sur Fire Stick.** C'est le pont entre votre Fire TV et l'application IPTV Smarters Pro.

1. Revenez à l'écran d'accueil et ouvrez l'**Appstore** (ou recherchez « Downloader » avec la loupe) ;
2. Sélectionnez **Downloader** (icône orange, édité par AFTVnews) ;
3. Cliquez sur **Télécharger** et patientez quelques secondes ;
4. Ouvrez **Downloader** et acceptez les autorisations demandées.

## Étape 3 : télécharger IPTV Smarters Pro

**L'APK d'IPTV Smarters Pro s'installe directement depuis le navigateur intégré de Downloader.** Deux méthodes s'offrent à vous :

### Méthode A — via l'URL officielle

1. Dans Downloader, saisissez l'adresse du site officiel de l'application dans la barre URL ;
2. Validez avec **Go** et attendez le chargement de la page ;
3. Cliquez sur le bouton de **téléchargement Android (APK)** ;
4. Une fois le fichier téléchargé, cliquez sur **Installer** ;
5. Confirmez par **Installer** puis **Ouvrir**.

### Méthode B — via un code court

Si la saisie d'URL est fastidieuse avec la télécommande, certains miroirs proposent un code numérique à taper dans Downloader. Notre e-mail de confirmation d'[abonnement IPTV](/iptv-france/) contient le lien direct le plus rapide.

## Étape 4 : configurer votre code IPTV dans l'application

**La configuration IPTV Smarters Pro se fait en une seule fois : trois informations copiées depuis votre e-mail de confirmation.**

1. Ouvrez **IPTV Smarters Pro** et cliquez sur **Ajouter un utilisateur** ;
2. Choisissez **Se connecter avec Xtream Codes API** (recommandé) ;
3. Renseignez les trois champs :
   - **Nom du profil** : par exemple `TV salon` ;
   - **URL du serveur** : l'adresse `http://…` fournie dans votre e-mail (sans `/get.php`, sans barre oblique finale) ;
   - **Identifiant et mot de passe** : vos identifiants Xtream Codes.
4. Cliquez sur **Ajouter un utilisateur** : les chaînes live, films et séries se chargent automatiquement.

La connexion Xtream est préférable au lien M3U car elle active l'EPG, les pochettes VOD et le catch-up. Notre article [où trouver votre code IPTV](/blog/code-iptv-activation/) détaille le format de ces identifiants.

## Vérifier la première lecture

**Après la première connexion, vérifiez trois réglages pour une expérience IPTV parfaite sur Fire Stick :**

- Lancez une chaîne HD et vérifiez que l'image et le son sont synchrones ;
- Ouvrez le guide TV : l'**EPG** peut demander 1 à 2 minutes pour se remplir ;
- Dans **Paramètres > Lecteur**, passez le décodeur en **HW** (matériel) et le tampon sur **Moyen**.

| Vérification | Réglage recommandé | Où le trouver |
|---|---|---|
| Décodeur vidéo | HW (matériel) | Paramètres > Lecteur |
| Taille du tampon | Moyen | Paramètres > Lecteur |
| Mise à jour EPG | Toutes les 24 h | Paramètres > EPG |
| Qualité par défaut | Auto (adaptative) | Paramètres > Lecteur |

## Dépannage : les 5 problèmes fréquents sur Fire Stick

| Problème | Cause probable | Solution |
|---|---|---|
| « Login failed » à la connexion | URL du serveur incomplète, espace caché ou identifiants erronés | Recopiez le serveur sans `/get.php`, vérifiez l'absence d'espace, respectez majuscules et chiffres |
| Image noire avec son | Décodeur logiciel dépassé | Paramètres > Lecteur > décodeur **HW**, ou lecteur externe VLC/MX Player |
| Buffering le soir | Saturation Wi-Fi 2,4 GHz ou serveur chargé | Passez en 5 GHz ou Ethernet, réglez le tampon sur Moyen |
| EPG vide | Guide pas encore chargé | Attendez 1-2 minutes puis forcez la mise à jour dans Paramètres > EPG |
| Application introuvable | APK non installé ou mémoire pleine | Relancez l'APK via Downloader et libérez de l'espace (Paramètres > Applications) |
