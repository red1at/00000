## L'IPTV sur PC : le confort du grand écran au bureau

**Installer IPTV Smarters Pro sur PC Windows ou Mac prend 3 minutes et transforme l'ordinateur en véritable poste de télévision avec EPG, VOD et favoris.** Le clavier facilite la saisie des identifiants, et l'application officielle couvre Windows 10/11 comme macOS.

C'est aussi le moyen le plus simple de tester votre [abonnement IPTV](/iptv-france/) avant de déployer sur la TV du salon — le même code fonctionne ensuite sur le [Fire Stick](/blog/installer-iptv-smarters-pro-fire-stick/), la Smart TV et le smartphone.

## Étape 1 : télécharger l'application officielle

**Téléchargez toujours le client IPTV Smarters Pro depuis le site officiel de l'éditeur, jamais depuis un miroir inconnu.**

1. Rendez-vous sur le **site officiel de l'application IPTV Smarters Pro** (section Downloads) ;
2. Choisissez la version **Windows** (.exe) ou **macOS** (.dmg) ;
3. Lancez le fichier téléchargé et suivez l'assistant d'installation ;
4. Ouvrez **IPTV Smarters Pro** depuis le menu Démarrer ou la barre des applications.

> Alternative rapide : **VLC** lit le lien M3U de votre abonnement (Média > Ouvrir un flux réseau). Pratique en dépannage, mais sans EPG ni VOD organisée.

## Étape 2 : configurer votre code IPTV

**Sur PC, la connexion Xtream Codes se fait au clavier : copier-coller depuis l'e-mail de confirmation, sans erreur de frappe.**

1. Dans IPTV Smarters Pro, cliquez sur **Add User** ;
2. Sélectionnez **Login with Xtream Codes API** ;
3. Renseignez les quatre champs :

| Champ | Contenu | Astuce |
|---|---|---|
| Profile name | `PC bureau` | Nom libre |
| Server URL | `http://serveur:port` | Sans `/get.php` ni `/` final |
| Username | Identifiant Xtream | Copier-coller de l'e-mail |
| Password | Mot de passe Xtream | Respect des majuscules |

4. Cliquez sur **Add User** : l'application charge les chaînes live, la VOD et l'EPG.

## Étape 3 : les réglages PC qui améliorent tout

**Quatre réglages optimisent la lecture IPTV Smarters Pro sur ordinateur, notamment en 4K :**

- **Accélération matérielle** : activez-la dans les réglages de l'application (HW decoding) pour déléguer le décodage au processeur graphique ;
- **Qualité adaptative** : laissez « Auto » sur laptop en Wi-Fi, forcez FHD sur Ethernet ;
- **EPG** : mise à jour automatique toutes les 24 h, avec 1-2 jours de guide passé pour le replay ;
- **Raccourcis clavier** : F pour le plein écran, flèches pour zapper, M pour couper le son — la navigation devient instantanée.

## Dépannage PC : les 5 cas fréquents

| Symptôme | Cause | Solution |
|---|---|---|
| « Login failed » | URL tronquée ou pare-feu | Recopiez l'URL complète ; autorisez l'app dans le pare-feu Windows |
| Vidéo saccadée | Wi-Fi lointain ou GPU inactif | Rapprochez-vous de la box, activez l'accélération matérielle |
| Écran noir avec son | Décodeur logiciel inadapté | Basculez le décodeur sur HW ou le lecteur externe VLC |
| Image figée à 20 h | Saturation du serveur en heure de pointe | Patientez 1-2 min ou basculez temporairement en FHD |
| Application lente au démarrage | Cache volumineux | Videz le cache dans les réglages de l'application |
